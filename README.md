# Code for European Methane Emission Assessment (2019–2023)

## Overview

This repository contains the Python code used to generate all figures presented in the main text of the manuscript:

**Sun, S., et al.**, *Assessment of methane emissions from European countries using satellite and surface observations*, **Atmospheric Chemistry and Physics (ACP)**.

The study assesses methane emissions across European countries from 2019 to 2023 using satellite and surface observations.

## Code Availability

The Jupyter Notebook (`code_ACP_public.ipynb`) contains the plotting code used to generate all figures in the main text of the manuscript.

This repository provides the visualization code and does not include the inversion model implementation.

## Data Availability

The national and sectoral methane emission estimates are provided in Table S1 of the Supplement accompanying the manuscript.

Additional information about the observational datasets and emission inventories used in this study is available in the manuscript and its references.
